# Write documentation in Simplified Technical English

## Why

Many readers of this repository do not have English as their first language.
Simplified Technical English gives each word one meaning and keeps sentences
short. Thus a reader understands a document on the first read, and a
translation stays correct.

## What the rule covers

- `README.md`, `DEVELOPMENT.md`, `CLAUDE.md` and each new document.
- Comments in the source code.
- Help text and error messages that a user reads.

## What the rule does not cover

- Code, with the identifiers.
- The output of a program, quoted in a code block.
- Rule files under `.observatory/` in other repositories.

The full list of rules is in the "Documentation rules" section of `README.md`.
